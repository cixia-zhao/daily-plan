## 本机最新交互（2026-10-20，未发布）

当前执行区提供小“补记刚才”，只在当前有效计时且计入统计时启用，不占下方四项快捷栏。约340px轻弹窗先选分心或厕所／生活，再点约1／2／5／10分钟即保存；其他分钟可手填，不填原因或设置提醒。保存后继续原任务／细分，日有效／目标实时纠正。错误留窗、取消不改记录、保存中防重复；响应丢失后同请求重试不重复扣减。

时间轴估计记录明确“补记·估计”；可展开修改起止，两侧有效边界同步，关联已变时拒绝覆盖。任务／分类／标签固定，操作为“撤销补记”，恢复有效时间。用户收工后停止计时，不扩大为全天娱乐记录，暂停／番茄钟未加入。

今天目标聚焦同时显示常用／历史候选，保留手填任意整数，箭头每档15分钟。精力档和当天类型默认隐藏，设置可分别恢复；隐藏时提交普通值。草稿科目采用纯文字，移除装饰符号。

设置“日常计划”可新建、移出和排序主项目、修改名字与默认分钟，也可加入已有项目。今天目标和草稿按该顺序生成，标签管理与临时活动同步读取动态类别；移出不改已保存日期和记录。项目身份使用稳定类别ID，改名不创建另一个项目。

执行台常态保存／待复盘状态不占可见空间，错误与请求中反馈保留；删除滚动按钮，四个快捷操作同排。时间轴默认位于任务后，仅有历史并展开且宽度至少1000px时左右排列。词数入口与提醒规则见文末19日补充。计时区新增当天当前项目累计有效／目标的进度条：按秒推进、休息分心冻结、达标继续计时、零目标不显示比例。运行中跟随实际活动所属项目，空闲可查看选中项目。用户反馈首版像黑线后，改为10px圆角陶土轨道与1.4秒流动纹理，达标继续学习仍播放；显示有效计时／分心／事务／停止状态及剩余／超额分钟，刚开始小标也能表达运行。休息、停止或减少动态效果时静止；暂停／番茄钟未扩展。

本机169项临时库测试和11组不同隔离浏览器通过；当前预览与未验证事项见HANDOFF.md。以下正式及历史段落按各自时点理解。

## 模块职责

提供电脑和手机都可用的服务端模板页面。浏览器只通过 JSON API 操作，不读密钥、不自行生成规则，也不会自动确认任务。当前前端核心已经从“今天页里全做完”升级成“今天页确认清单，执行台记录白天，复盘页回看数据”。

## 已知问题与注意事项

- 桌面端每栏固定显示五个槽位；移动端隐藏普通空槽，暂停运动卡仍保留。
- 今天页负责“确认清单”，执行台负责“白天记录”，单日复盘页负责“回看与晚间收束”；不要把三者职责重新混回一个页面。
- 执行台只对 `approved` 或 `submitted` 的日期开放；草稿状态会显示引导空态。
- 同一时刻全局只允许一个激活段；如果后续改交互，不要在前端做出“双计时”假象。
- 中断标签不并入任务总时间，但仍会显示在任务看板里。
- 有效细分标签是“任务类别级配置”，不是每天单独配一套。
- 目前默认维护方向是桌面端和手机端一致，不再故意分叉成“手机一版、桌面一版”。
- 执行台时间轴支持补记、编辑、删除；这块在手机上最容易暴露触控和日期输入问题。
- 设置页的执行标签分为系统标签和自定义标签；系统标签可改名、改归类但不可删。
- 设置页的主航线草稿默认分钟现在默认是 0；如果后续觉得太极端，要改的是设置值，不是再把代码默认分钟写死。
- 单日复盘页和七日复盘页都支持“复制给 GPT -> 粘贴回项目”的手工协作闭环。
- 当前只做响应式页面，没有 PWA、离线缓存或前端构建链。
