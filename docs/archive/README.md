# 历史归档目录（docs/archive/）

本目录集中存放项目早期阶段生成的单次设计调研、十月份历史发布单、旧过程截图与已退役脚本，仅供追溯历史演进时手动查阅。

> **注意**：日常功能开发、缺陷排查与 AI 代理上下文读取时，**请勿扫描或加载本目录下的文件**，当前现役规范请直接查阅根目录 `AGENTS.md`、`HANDOFF.md`、`DESIGN.md` 与 `docs/README.md`。

## 子目录说明
- `handoff-history-2026-11.md`：2026 年 11 月 18 日重构前的完整历史交接记录备份。
- `releases/`：2026 年 10 月份的早期生产发布记录。
- `studies/`：早期单次需求审计、视觉参考、时间轴草图调研与旧版部署说明。
- `design-previews/`：早期各轮界面改版留存的静态对比截图。
- `legacy-scripts/`：早期 Windows `.cmd`/`PowerShell` 与 Android Termux 本机启动脚本归档。
