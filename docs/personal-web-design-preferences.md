# 我的网页设计偏好

根据「今日航线」截至2026-11-06的使用反馈整理，供下次做网站时参考。依据包括本人明确提出的要求、历次修改记录与实际页面；当前实现中的具体数值只作参考，不表示每个细节都已获实机认可。

**我喜欢温暖、克制、有纸面层次的界面；常用操作顺手直接，复杂细节需要时再打开，同类控件始终保持熟悉。**

## 1. 颜色安静，内容清楚

我明确喜欢暖纸、米白、沙色、炭黑，以及少量陶土色。可以参考Claude Code产品官网的书刊气质，再做出自己的内容与布局。当前不喜欢绿色主主题、高饱和彩虹式分类和满屏强调色。

颜色先分工：浅色做背景，深色保证阅读，强调色标记当前选择和关键进度。数据确实需要区分类别时，可以使用少量低饱和配色，同时保留名称。

标题可以有一点衬线字体的书卷感，正文、输入和按钮优先清楚。数字与单位分层，重点自然突出。

## 2. 质感来自细节配合

我说的“有质感”，具体可以落在：舒服的内边距、对齐的边线、细而清楚的边框、轻微的表面层次，以及按下时恰当的反馈。

普通列表用留白和轻分隔就够了，浮起的菜单、按钮和弹窗可以有轻阴影。避免每行都套一张大卡片、层层嵌框，或用玻璃、发光和装饰渐变表达精致。

在本项目中，清单贴字、按钮忽大忽小、弹窗像临时拼起来，都会破坏这种感觉。判断时看实际手机页面，设计示意图只能作方向参考。

## 3. 同一种功能，保持同一种细节

关闭、返回、添加、保存这些动作，在不同页面应有稳定的位置、尺寸、圆角、图标粗细和反馈。用户学会一次，换个页面还能顺手操作。

可以有主按钮、次按钮、图标工具等多种样式，但各自职责要稳定。比如主要确认动作突出，右上角管理工具轻一些；不用把设置页、图表页和清单页都做成同一排大卡片。

当前项目常用触控区域至少44px，新图标按钮内部图形约18px。这些是起点，具体尺寸按新项目调整，同类控件一起调整。

## 4. 熟悉的动作可以用图标

我明确希望添加用加号、管理用编辑图标、返回用箭头、关闭用叉号。它们放在熟悉的位置，能减少文字占用，让界面更利落。

具体业务动作仍需表达结果，例如“修正时间”“保存并返回”“确认移除”。陌生或可能误解的功能，可以保留简短文字。手机无法依靠鼠标悬停解释含义，图标本身也要有可供辅助技术读取的名称。

**少写重复说明，让位置和外观帮助理解；必要的话仍然说清楚。**

## 5. 常用操作直接做，细节按需打开

我喜欢常用分钟、历史候选、自定义快捷项，能点选就少打字。快捷项最好可以在使用的地方直接添加，避免为了一个新习惯跑进多层设置。

快捷入口与详细入口都要有：吃饭30分钟可以一下完成；游戏20分钟、结束10分钟前这种情况，也应有清楚的详细修正。默认画面先照顾高频场景，更多设置、历史和管理再按需展开。

重要入口仍要容易发现。频繁用的操作不宜全部藏在“更多”里，桌面有足够空间时也可以常驻。

## 6. 手机紧凑，文字和点击区域仍然舒服

我在意手机纵向空间，常用流程尽量一屏内完成。优先删重复标题、常态说明和无用空白，保留正常字号、必要滚动与足够大的点击区域。

手机可以用底部抽屉，复杂选择在同一窗口切换内容；电脑可以展开菜单或把常用面板放在右侧。两边用同一套视觉语言，布局根据空间安排。

长名称、三位数输入、软键盘、短屏和较多记录都要看实际效果。单看整页没有横向溢出，还不能证明内部输入框和按钮没有被挤窄。

## 7. 动效帮助理解位置和状态

我接受短而有方向的切页、返回、抽屉展开和跟手拖动，也明确要求进度条的运行反馈看得出来。

动效应告诉我内容去了哪里、现在是否在运行；避免为装饰反复闪烁或播放。切页尽量稳定，返回保留选择与滚动位置，并兼顾减少动态效果的系统设置。

## 8. 方便修正，操作后有把握

忘记切活动、估错时间是正常使用场景。界面应方便补记、修改和撤销，减少回到历史逐条修理的负担。

普通快捷操作直接完成并给反馈；删除等容易造成损失的动作再确认。保存失败保留输入，返回保留选择，网络恢复自动重连。反馈要对应实际结果，不能让人分不清“正在保存”和“已经成功”。

这是我对顺手、可靠的体验的明确要求；适用于很多网站，具体确认方式仍按操作影响决定。

>

如果下次想尝试不同配色，可以只替换第一段；操作习惯与一致性要求仍可保留。鱼骨导航、计时侧栏等是「今日航线」的具体方案，是否复用取决于新网站的用途。

## 看设计时，先检查这五件事

1. 第一眼知道现在在哪、最常用的操作在哪吗？
2. 同样的关闭、返回、保存，换页后仍然熟悉吗？
3. 手机能清楚阅读、准确点击，详细内容也方便打开吗？
4. 输入、等待、失败和返回之后，状态与内容还在吗？
5. 去掉装饰后，排版、层次和操作本身仍然舒服吗？

本页是一份可以继续修订的个人参考。明确喜好主要是暖纸气质、熟悉动作图标化、同类细节统一、快捷与详细并存，以及对手机空间的重视；其余归纳来自这些要求的反复表现，不视为永久定论。
