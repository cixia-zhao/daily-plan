# 手机细分与紧凑界面发布（2026-10-14）

用户已确认本轮调整方向并授权提交 GitHub、正式部署。本文件先记录发布准备；实际应用版本、发布时间、备份和线上验收在发布成功后补齐。

## 发布内容

- 同一任务计时中点击网课／刷题实际切换细分，旧计时结束；重复点击当前细分不新增记录，细分触控区域至少 44px。
- 执行卡片从事项类型以下全部默认折叠，包含有效细分，操作后保留展开状态。
- 日期统一顶部右对齐，移除可见“日期”标签；手机今天清单标题与日期同排，附属操作靠右，默认清单一屏操作保留。
- 临时添加活动与旁边快捷入口统一透明描边。
- 单日复盘用数据看板／收尾与深聊两个页签，默认数据看板；切换保留输入，支持键盘操作。
- 今天页与单日复盘直接显示重置今天，保留确认弹窗。
